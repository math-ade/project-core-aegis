# 🛡️ AegisOps-Insights // Live System Telemetry Engine

Welcome to my enterprise-grade full-stack telemetry visualization platform. This project reads live server performance data and streams it directly to a beautiful, responsive dark-mode user interface.

🌐 **Click Here to See My Live Hosted Dashboard:** [https://github.io](https://github.io)

## 🏗️ How the System Works
1. **The Server Layer:** Tracks live resource and memory limits directly out of the host Linux operating system.
2. **The Backend Layer (Python & FastAPI):** An asynchronous Python API that collects these server metrics and shares them as clean data payloads.
3. **The User Interface (HTML, CSS & JavaScript):** A gorgeous web dashboard that automatically talks to the backend every 2 seconds, drawing live, animated charts using **Chart.js**.

## 🛠️ The Tech Stack
- **Frontend UI:** HTML5, CSS3 (Glassmorphism design), JavaScript, Chart.js.
- **Backend Core:** Asynchronous Python 3.12, FastAPI, Uvicorn Server.
- **Hosting Infrastructure:** GitHub Pages static cloud delivery.
